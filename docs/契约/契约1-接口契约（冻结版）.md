## 契约 A：`fir_core` 的端口（A 实现，B 例化）

```verilog
module fir_core #(
    parameter DW   = 16,        // 数据位宽 Q1.15
    parameter CW   = 16,        // 系数位宽 Q1.15
    parameter AW   = 40,        // 累加器位宽（下限 38，取 40）
    parameter NTAP = 82         // 抽头数
)(
    input  wire                    clk,
    input  wire                    rst_n,
    input  wire                    flush,       // 清空延迟线与流水线（系数保留）
    input  wire                    en,          // 每拍处理一个样本
    input  wire signed [DW-1:0]    din,
    output wire signed [DW-1:0]    dout,
    output wire                    dout_v,      // dout 有效标志（与 dout 同拍）
    input  wire [$clog2(NTAP)-1:0] coef_idx,    // 系数写口：第几个
    input  wire signed [CW-1:0]    coef_din,    // 系数写口：值
    input  wire                    coef_we      // 系数写口：写使能（一拍）
);
```

行为约定（A 必须做到，B 依赖这些）

| # | 约定 |
|---|---|
| A1 | 吞吐 1 sample/cycle：`en` 连续拉高时，`dout_v` 每拍都有效 |
| A2 | 流水线延迟固定 5 拍：`en` 拉高后第 5 拍 `dout_v` 拉高 |
| A3 | `dout_v` 与 `dout` 同拍对齐（`dout_v=1` 那一拍 `dout` 就是它标记的结果） |
| A4 | `flush` 拉高一拍：延迟线与流水线全部清零，`dout_v` 保持 0；系数保留 |
| A5 | `coef_we` 拉高一拍：把 `coef_din` 写入 `h[coef_idx]`（可随时写，不影响数据流） |
| A6 | 定点规则：乘积 Q2.30 精确，累加 40bit 不溢出，输出右移 15 位回 Q1.15 并饱和 |

时序图（en / din / dout / dout_v 的关系）

```
clk      _/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_/‾\_
en       __/‾‾‾‾‾‾‾‾‾‾\____________________________
din      XX<   s0   ><   s1   >X__________________
         ├──────── 延迟 5 拍 ────────┤
dout_v   ______________________________/‾‾‾‾‾‾‾‾‾
dout     XXXXXXXXXXXXXXXXXXXXXXXXXXXXXX<   y0   ><  y1
                                        ↑
                     dout_v=1 的这一拍，dout 就是它标记的那个结果（A3）
```

验收方法：契约自检台（把约定变成可执行的检查）

`TB/tb_fir_core_contract.v` 把上面 6 条约定写成了自动检查。
A 写完实现后跑一遍，全绿才算守住契约：

```
iverilog -g2012 -o sim.out RTL/fir_core.v TB/tb_fir_core_contract.v
vvp sim.out
```

| 自检用例 | 验的是哪条约定 |
|---|---|
| 延迟拍数 = 5 | A2 |
| `dout_v` 那一拍的 `dout` 值正确 | A3 |
| `flush` 后无 `dout_v`，且系数保留 | A4 |
| 连续 40 拍 `en` → 恰好 40 个结果 | A1（吞吐） |
| 最坏情况（81 个 −32768 系数 × −32768 输入）应正饱和到 +32767 | A6（32bit 累加会回绕，这条专抓它） |
| 运行中改系数立刻生效 | A5 |

>  拿只有端口的空壳跑会全红——那是当然的，空壳没有实现。
> 这个台子是给 A 写完实现后的验收标准，也是评审时"接口守住了"的证据。

> 起点：`RTL/fir_core.v` 里已经放了一个只有端口的空壳，A 用它当起点，把内部实现补全。
> 端口一个都不许改。

## 契约 B：`fir` 顶层对外端口

> 权威来源：[`docs/任务4-模块接口信号清单.md`](任务4-模块接口信号清单.md) 第 1.5 节
> 本文不重复抄写。要点：

- AXI4 从口，5 通道，带 ID（`ID_W = 4`）
- 端口前缀统一用 `s_axi_`（如 `s_axi_awaddr`、`s_axi_rdata`）
- `irq_done` → IRQ0（滤波完成，电平，读 STATUS 清除）
- `irq_err` → IRQ1（错误：溢出 / 读空）
- 基址 `0x4000_0000`

## 契约 C：`fir` 的寄存器映射

> 权威来源：[`docs/任务3-地址映射与中断分配.md`](任务3-地址映射与中断分配.md) 第 4.1 节

| 偏移 | 名称 | 访问 | 说明 |
|---|---|---|---|
| `0x000` | CTRL | W | bit0=1 清空延迟线与输出 FIFO |
| `0x004` | DIN | W | 写一个样本（低 16bit，Q1.15） |
| `0x008` | DOUT | R | 读一个滤波结果（低 16bit） |
| `0x00C` | STATUS | R | `fifo_count / fifo_full / fifo_empty / done / err`（位定义见任务三 4.1） |
| `0x100 + 4·k` | COEF[k] | W | 第 k 个系数（k=0..80），占 0x100~0x244 |

### STATUS 的 done / err 位（已确认）

`任务三` 4.1 已补充 STATUS 位定义，`[2]=done`、`[3]=err`（不动 `[0][1]`）：

| 位 | 名称 | 说明 |
|---|---|---|
| [0] | `fifo_empty` | 无结果可读 |
| [1] | `fifo_full` | FIFO 满（再写会丢） |
| [2] | `done` | 有待读结果（= `!fifo_empty`），读 STATUS 清除 `irq_done` |
| [3] | `err` | 溢出/读空错误，读 STATUS 清除 `irq_err` |
| [15:4] | 保留 | 读回 0 |
| [31:16] | `fifo_count` | 当前可读结果个数 |
