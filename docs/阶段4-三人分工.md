## 1. 第一步：冻结顶层端口 + 定一个决策（三人一起，10 分钟）

### 契约 S：`soc_top` 的对外端口

```verilog
module soc_top #(
    parameter ADDR_W     = 32,
    parameter DATA_W     = 32,
    parameter ID_W       = 4,
    parameter SRAM_BYTES = 65536,       // 片内 SRAM 大小（64KB）
    parameter CLK_FREQ   = 100_000_000, // 时钟频率（Hz），给 UART 算波特率用
    parameter UART_DIV   = 10           // UART 分频：BAUD = CLK_FREQ / UART_DIV
)(
    input  wire clk,        // 单一时钟域（仿真里可用 100MHz，综合目标 50MHz）
    input  wire rst_n,      // 低有效异步复位
    output wire uart_txd,   // UART 发送（对外引脚）
    input  wire uart_rxd    // UART 接收（对外引脚）
);
```

**这是本阶段唯一需要冻结的东西** —— C 的 `tb_soc.v` 要按它例化。

> **`UART_DIV` 怎么落到 UART 上**：`RTL/uart_apb.v` 的参数是 **`CLK_FREQ` / `BAUD`**（**不是分频系数**），
> 所以 `soc_top` 内部必须换算：`uart_apb #(.CLK_FREQ(CLK_FREQ), .BAUD(CLK_FREQ / UART_DIV))`。
> 例：`CLK_FREQ=100MHz`、`UART_DIV=868` → `BAUD≈115200`（标准波特率）；
> 仿真想省时间就把 `UART_DIV` 调小（每 bit 占的时钟数变少）。

> **SWD 调试口**：本 IP **不暴露 SWD/SWDIO/SWCLK 端口**（已核对 `RTL/cpu/cortexm0ds/`），
> 因此顶层没有需要固定电平的调试脚 —— 早期版本这里写的「A 在顶层固定电平」应删除。

### 决策 D1：ROM Boot 做不做？（**必须先定**）

阶段 4 原文写的是「**可选** ROM Boot」。两条路：

| 方案 | 地址映射 | 代价 |
|---|---|---|
| **A（规范）** | ROM @`0x0000_0000`（放固件）+ SRAM @`0x2000_0000` | 多写一个 `axi_rom.v`，还要处理"固件怎么装进 ROM" |
| **B（推荐，初赛）** | **SRAM @`0x0000_0000`**（程序+数据+栈共用 64KB），不做 ROM | 省一个模块、省半天调试 |

**推荐 B**：M0 复位后从 `0x0` 取向量表和入口，只要 `0x0` 有可读存储器就能启动。
初赛不考查 ROM/SRAM 分区，报告里注明"初赛简化处理"即可。

> ⚠️ **这个决定直接决定 B 的 SRAM 挂在哪**（`0x0` 还是 `0x2000_0000`），所以必须第 1 天定。
>
> ✅ **已定：采用方案 B —— SRAM @ `0x0000_0000`，不做 ROM。**
> 落地时的**唯一关键点**：`axi_sram` 要接 `axi_ic` 的 **`m3_axi_*`**（不是 `m2`），
> `BASE_ADDR` 用默认值 `0`。原因见下面「地址映射」表的注释 —— 互连译码把 `0x0` 给的是 `m3`。

### 地址映射（`docs/任务三`，按方案 B 调整）

| 基地址 | 大小 | 模块 | 互连主口 |
|---|---|---|---|
| `0x0000_0000` | 64KB | **片内 SRAM**（程序+数据+栈） | **`m3`** |
| `0x4000_0000` | 4KB | FIR | `m0` |
| `0x4000_1000` | 4KB | DMA 配置口 | `m1` |
| `0x4000_2000` | 64KB | AXI→APB 桥（内含 UART） | `m4` |
| ~~`0x2000_0000`~~ | — | 方案 B 不用（`m2` 留空） | — |

> ⚠️ **`m2` / `m3` 千万别弄反**（本文件早期版本这里写错过）：
> `axi_ic.v` 的译码函数 `f_decode` 里是
> `a[31:16]==16'h0000 → 3'd3`（**m3**）、`a[31:16]==16'h2000 → 3'd2`（**m2**）。
> **互连的主口编号和本表的行序不是一回事**，`0x0` 这一段落在 **`m3`**。
> 所以方案 B 的 SRAM **必须接 `m3_axi_*`**、并用 `BASE_ADDR` 默认值 `0`。
> 若接到 `m2`，SRAM 的实际地址就变成 `0x2000_0000`，而 CPU 复位从 `0x0`
> 取向量表会打到悬空的 `m3` 上 → DECERR → **SoC 起不来**。
> `m2` 留空时请接**静态无效值**（`awready/wready/bvalid/rvalid=0` 等），不要悬空。

**主设备**：CPU（AHB→AXI，ID=0）、DMA（ID = `{CH[2:0], 1'b1}`）。

## 2. 三人分工

### 👤 A —— SoC 顶层集成

| 项 | 内容 |
|---|---|
| **新建文件** | `RTL/soc_top.v`（只有这一个） |
| **分支** | `phase4-A-soc-top` |

**要做**

1. 按 §1 的地址映射把 9 个模块连起来：

```
     cortexm0ds_logic（RTL/cpu/cortexm0ds/cortexm0ds_logic.v）  ← AHB-Lite 核
           │ AHB-Lite
     ahb2axi（RTL/ahb2axi.v）                    ← 主设备 ID = 0
           │ AXI4
     axi_ic（RTL/axi_ic.v）+ axi_arbiter          ← 2 主 5 从（方案 B 实接 4 个）
       ├─ m0 → fir（RTL/fir.v）          @0x4000_0000
       ├─ m1 → dma（RTL/dma.v）          @0x4000_1000
       ├─ m3 → axi_sram（RTL/axi_sram.v，B 已交付）          @0x0000_0000   ← 是 m3，不是 m2！
       ├─ m2 → 方案 B 不用（接静态无效值，别悬空）
       └─ m4 → axi_to_apb（RTL/axi_to_apb.v）
                    │ APB
                    └─ uart_apb @0x4000_2000
```

> ⚠️ **CPU 用哪个文件必须写死**（早期版本这里含糊，会导致 `ahb2axi.v` 白写或白连）：
> `RTL/cpu/cortexm0ds/` 下有**两个**可当 CPU 的模块，接口完全不同：
>
> - **`cortexm0ds_logic.v`** —— 纯 **AHB-Lite** 核（`haddr_o/htrans_o/hwrite_o/hsize_o/hburst_o/hwdata_o`，
>   反向 `hrdata_i/hready_i/hresp_i`）。**本设计用它**，经我们的 `ahb2axi.v` 转成带 **ID=0** 的 AXI4 ——
>   这条链路阶段 2 已单独验过（17 项）。
> - `cortexm0ds.v` —— 内部已例化 ARM 自带的 `ahb2axi4_if`，**对外直接是 AXI4，而且没有任何 ID 信号**。
>   用它的话我们 B 的 `ahb2axi.v` 完全用不上，还得在顶层把互连从口的 ID 输入绑成 0。**本设计不采用。**

2. **统一时钟/复位**：全片单一时钟域，复位同步释放
3. **中断连线**：FIR `irq_done`→IRQ0、`irq_err`→IRQ1；DMA `irq_done[5:0]`→IRQ2~7、`irq_err`→IRQ8
4. **UART 分频**：把顶层的 `UART_DIV` 换算成 `uart_apb` 的 `CLK_FREQ` / `BAUD`
   （`BAUD = CLK_FREQ / UART_DIV`，两者都是 `soc_top` 的参数，见 §1）

**验收**

- [ ] 整个 SoC 能编译（`iverilog -g2012 -Wall` 零告警）
- [ ] 冒烟：CPU 能读写 SRAM、能读 FIR 的 STATUS（由 C 的 TB 验）
- [ ] 地址映射与 §1 的表逐条一致

**怎么不被 B 卡住**：先用**空壳 SRAM**（端口齐全、读返回 0）把顶层连起来跑通，
B 的真 SRAM 到了直接替换。
