## 1. 第一步：冻结三个接口（三人一起，10 分钟）

**这是全部分工的前提。定下来之后谁都不许私改，改了要三人一起返工。**

### 1.1 契约 A：FIR 数据通路 `fir_core` 的端口（A 实现，B 例化）

```verilog
module fir_core #(
    parameter DW   = 16,        // 数据位宽 Q1.15
    parameter CW   = 16,        // 系数位宽 Q1.15
    parameter AW   = 40,        // 累加器位宽（下限 38，取 40）
    parameter NTAP = 81         // 抽头数
)(
    input  wire                    clk,
    input  wire                    rst_n,
    input  wire                    flush,       // 清空延迟线与流水线（系数保留）
    input  wire                    en,          // 每拍处理一个样本
    input  wire signed [DW-1:0]    din,
    output wire signed [DW-1:0]    dout,
    output wire                    dout_v,      // dout 有效标志
    input  wire [$clog2(NTAP)-1:0] coef_idx,    // 系数写口
    input  wire signed [CW-1:0]    coef_din,
    input  wire                    coef_we
);
```

### 1.2 契约 B：FIR 顶层 `fir` 的对外端口（**`docs/任务四` 1.5 节已定，不许改**）

- AXI4 **从口**，5 通道，**带 ID**（`ID_W = 4`）
- `irq_done` → IRQ0（滤波完成，电平，读 STATUS 清除）
- `irq_err` → IRQ1（错误：溢出 / 读空）
- 基址 `0x4000_0000`

### 1.3 契约 C：寄存器映射（**`docs/任务三` 4.1 节已定**）

| 偏移 | 名称 | 访问 | 说明 |
|---|---|---|---|
| `0x000` | CTRL | W | bit0=1 清空延迟线（flush） |
| `0x004` | DIN | W | 写一个样本（16bit，Q1.15） |
| `0x008` | DOUT | R | 读一个滤波结果（16bit） |
| `0x00C` | STATUS | R | `fifo_count / fifo_full / fifo_empty` |
| `0x100 + 4·k` | COEF[k] | W | 第 k 个系数（k=0..80），占 0x100~0x244 |

### 1.4 契约 D：系数文件格式（C 生成，A/B 消费）

```verilog
// coeffs.vh
localparam signed [15:0] H0 = 16'sd20;
...
```
```
// coeffs.hex —— 每行 4 位十六进制补码，供 $readmemh
0014
FFEC
...
```

> ⚠️ **待确认**：`任务三` 的 STATUS 只定义了 fifo 相关位，但 `任务四` 要求
> `irq_done` 是"读 STATUS 清除"的电平信号 —— **STATUS 的 done/err 位定义需要补**。
> 这件事由 **B** 在开工前找队友（写任务三的人）确认，确认后补进契约 C。

## 2. 三人分工

### 👤 A —— FIR 数据通路（DSP 核心）

| 项 | 内容 |
|---|---|
| **文件** | 新建 `RTL/fir_core.v` + 新建 `TB/tb_fir_core.v` |
| **分支** | `phase1-A-core` |

**要做**（对应图片第 1、3 条）

- 延迟链 81 级 + 全并行乘法（81 个 16×16）
- 累加用 **7 级加法树**（81→41→21→11→6→3→2→1），**不是串行链**
- 加法树分 3 段打拍，共 **5 级流水**（吞吐仍 1 sample/cycle）
- 输出：右移 15 位回 Q1.15 + **饱和**
- 系数寄存器（可运行时写）
- **预留「对称系数优化 81→41」的改法**：写成参数 + 注释钩子（本阶段不实现）

**验收**

- [ ] 流水线延迟恰为 5 拍（专门用例测）
- [ ] `flush` 后延迟线与流水线彻底清空
- [ ] 81 阶全量样本与 golden model **逐位一致**
- [ ] 端口严格等于契约 A
- [ ] `-Wall` 编译零告警

**起点**：`fir_soc/rtl/fir_cfg.v` 里那版流水线实现已经验过（延迟 5 拍、336 样本逐位一致），可以拿来当底子，但**端口要按契约 A 调整、文件放到 `RTL/`**。

**commit message**
```
feat: 新增 FIR 数据通路 fir_core.v（7 级加法树 + 5 级流水）

- 81 级延迟链 + 81 个 16x16 并行乘法
- 累加用 7 级加法树（非串行链），分 3 段打拍，共 5 级流水
- 吞吐 1 sample/cycle，输出右移 15 位回 Q1.15 并饱和
- 端口按 docs/任务四 契约；预留对称系数优化的参数钩子
- TB 验证：延迟 5 拍 / flush 干净 / 81 阶逐位一致
```

### 👤 B —— FIR 的 AXI4 从接口 + 中断

| 项 | 内容 |
|---|---|
| **文件** | 新建 `RTL/fir.v` + 新建 `TB/tb_fir.v` |
| **分支** | `phase1-B-axi` |

**要做**（对应图片第 2、4 条）

1. **AXI4 从口（5 通道，带 ID）**——不是 AXI-Lite。要处理：
   - `AWID/ARID → BID/RID` 透传
   - `AWLEN/ARLEN`、`WLAST/RLAST`
   - `WSTRB` 写选通
   - **单拍（LEN=0）+ INCR 突发**（地址按 SIZE 递增；突发不跨 4KB）
   - 遵守 VALID/READY 铁律：**VALID 不许等 READY**，通道之间不许有组合环
2. **寄存器映射**严格按契约 C
3. **系数下发**：AXI 写 `COEF[k]` → 经 `coef_we/coef_idx/coef_din` 写入 `fir_core`
4. **样本下发**：AXI 写 `DIN` → `en` 一拍 + `din`
5. **结果回读**：`fir_core` 的 `dout/dout_v` → 输出 FIFO → AXI 读 `DOUT`
6. **中断**：`irq_done`（结果可取，读 STATUS 清）、`irq_err`（溢出/读空）

**验收**

- [ ] 单拍读写全部通过
- [ ] **INCR 写突发**（多拍 DIN）+ **INCR 读突发**（多拍 DOUT + RLAST）通过
- [ ] 突发期间无协议违规（可用简易协议检查器断言）
- [ ] 对外端口严格等于 `docs/任务四` 1.5 节
- [ ] 寄存器地址严格等于契约 C

**commit message**
```
feat: 新增 FIR 的 AXI4 从接口与中断（RTL/fir.v）

- AXI4 五通道从口，带 ID（ID_W=4），支持单拍与 INCR 突发
- 寄存器映射按 docs/任务三 4.1：CTRL/DIN/DOUT/STATUS/COEF[k]
- 中断：irq_done（结果可取，读 STATUS 清）、irq_err（溢出/读空）
- 内部例化 fir_core.v，系数经 coef 写口下发
- TB 覆盖：单拍读写 / INCR 写突发 / INCR 读突发 + RLAST / 错误响应
```

**要做**（对应图片第 1、5 条）
