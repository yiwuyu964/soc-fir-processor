# fir_soc 抢救清单与文件对应关系

> **文档信息** ｜ 类别：参考与手册类 ｜ 所属：跨阶段 ｜ 状态：参考 ｜ 索引：`docs/README.md §1.5`
> **背景**：`fir_soc/` 是早期一路学习做出来的原型。它的地址映射、模块划分与
> `docs/任务三`、`docs/任务四` 两份契约**不一致**（AXI-Lite 而非 AXI4、无 ID、无中断、
> 地址对不上），继续参考容易搞混，因此决定从库里移除。
>
> **但里面有一批"不是学习实验、而是照着赛题做出来的真东西"**，删之前必须抢救出来。
> 本文就是抢救的记录：谁搬到了哪、对应规范里的哪个模块、验证到什么程度。
>
> 完整备份在：`比赛\_资料\fir_soc_完整备份\`（91 个文件），需要什么还能回去拿。

## 8. 后续清理：从 `RTL/` 移除旧架构遗留（2026-10-11）

抢救时把 `fir_soc/rtl/` **整个目录**复制进了 `RTL/`，其中 9 个文件属于**旧架构遗留**，
接口形态与 `docs/任务四` 契约不符。这些文件已移除，由队友按契约重写：

| 已从 `RTL/` 删除 | 原因 |
|---|---|
| `axi4_to_axilite.v` | 旧协议转换桥，新架构用不到 |
| `axi_lite_xbar.v` | AXI-Lite 单主互连 → 将由 **AXI4 2主5从 crossbar** 取代 |
| `axi_lite_sram.v` | AXI-Lite → 需改 **AXI4**，且地址挪到 `0x2000_0000` |
| `soc_top.v` / `soc_cm0_top.v` | 旧 SoC 顶层，**地址映射与规范不符** |
| `uart_axi.v` | 被 `uart_apb.v`（契约⑨）取代 |
| `fir_cfg.v` | 被 `fir_core.v`（契约⑤）取代 |
| `fir_axi.v` | AXI-Lite → 将按契约⑤重写为 **AXI4 + 中断** |
| `dma.v` | 无中断输出 → 将按契约⑥重写 |

**对应旧测试台一并删除**（它们测的是被删的旧接口）：
`tb_axi_sram.v`、`tb_dma.v`、`tb_fir_axi.v`、`tb_soc.v`、`tb_fir_cfg_pipe.v`

### 教训

**抢救文件宁可少抄不可多抄。** 只搬"确认最终设计要用的"，
拿不准的先留在 git 历史和备份里。否则只是把垃圾从一个目录搬到另一个目录，
队友还得再清一遍。
