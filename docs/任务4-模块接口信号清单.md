# 任务四：各模块对外接口信号清单

> 本文件是**接口契约的第二张表**（第一张是《任务三_地址映射与中断分配.md》）。
> 先定接口、再写 RTL：所有 RTL 端口名、Testbench 连线、C 驱动里的寄存器名，都以本文件为准。
> 约定：`in/out` 均**从模块自身视角**定义；全片**单一时钟域 hclk（50MHz）**。

## 0. 全局约定

### 0.1 位宽参数

| 参数 | 值 | 说明 |
|---|---|---|
| `DATA_W` | 32 | AXI/AHB/APB 数据宽度 |
| `ADDR_W` | 32 | 地址宽度 |
| `ID_W` | 4 | AXI 事务 ID 宽度（区分 2 个主设备） |
| `LEN_W` | 8 | AXI 突发长度 |
| `SIZE_W` | 3 | AXI 传输粒度编码 |
| `BURST_W` | 2 | AXI 突发类型（FIXED/INCR/WRAP） |
| `STRB_W` | 4 | 写字节选通（32bit/8） |

### 0.2 时钟域

| 信号 | 时钟域 | 说明 |
|---|---|---|
| 全部 AXI/AHB/APB | `hclk`(50MHz) | 单一时钟域，无跨时钟(CDC)问题 |
| `uart_txd/uart_rxd` | `hclk` 片内采样 | 对外是异步串行线，片内用分频器采样/发送 |

### 0.3 AXI4 标准信号模板（5 通道）

**主口（前缀 `m_`）**：`awid[3:0] awaddr[31:0] awlen[7:0] awsize[2:0] awburst[1:0] awvalid awready`
`wdata[31:0] wstrb[3:0] wlast wvalid wready` `bid[3:0] bresp[1:0] bvalid bready`
`arid[3:0] araddr[31:0] arlen[7:0] arsize[2:0] arburst[1:0] arvalid arready`
`rid[3:0] rdata[31:0] rresp[1:0] rlast rvalid rready`

**从口（前缀 `s_`）**：同名信号，方向与主口相反。

### 0.4 AHB-Lite / APB4 标准信号模板

- **AHB-Lite 主口（CPU 侧）**：`HADDR[31:0] HTRANS[1:0] HWRITE HSIZE[2:0] HBURST[2:0] HPROT[3:0] HMASTLOCK HWDATA[31:0]`（输出）＋ `HRDATA[31:0] HREADY HRESP`（输入）
- **AHB-Lite 从口（桥 AHB 侧）**：上述信号反向 ＋ `HSEL`（片选，来自译码）
- **APB4**：`PADDR[31:0] PSEL PENABLE PWRITE PWDATA[31:0]`（主→从）＋ `PRDATA[31:0] PREADY PSLVERR`（从→主）

> 说明：**"外设寄存器接口"统一指「内存映射寄存器」**，即通过 AXI/APB 从口读写某段地址空间，
> 不再单列并行寄存器总线；**"存储接口"就是 SRAM/ROM 的 AXI 从口**（若例化 FPGA BRAM 原语，
> 其原生口属模块内部，不在对外清单）。

## 3. 为什么这样写、依据是什么

### 3.1 为什么要"先接口后 RTL"、且接口必须和地址/中断两张表咬合
阶段 0 计划里写死了一条顺序：**模块划分 → 框图 → 地址/中断映射 → 接口清单 → 才写 RTL**。
接口清单是前两张表（地址映射、中断号）**落到物理连线上**的产物：
- 地址映射表决定"谁挂哪条总线、基址多少" → 本表决定"这条总线连到哪个端口、位宽多少"；
- 中断分配表决定"IRQ 几号是谁" → 本表决定"这条 irq 线从哪个模块的哪个端口出来、接进 CPU.IRQ[几]"。
三者不一致会导致 RTL 返工，所以本表每个基址、每个 IRQ 号都能在《任务三》里对上号。

### 3.2 为什么总线接口要统一成 AXI4 五通道、且从/主口用 s_/m_ 前缀
- 赛题硬性要求 AXI 支持**单拍 + Burst(INCR)**，且 FIR/DMA/CPU 都挂 AXI，所以总线接口必须是**标准 AXI4**（含 AWLEN/AWSIZE/AWBURST，才能表达 INCR）；
- 用 `s_`/`m_` 前缀 + 标准通道名，**任何看过 AMBA 规范的人都能一眼读懂方向**，满足"代码规范性"评分；
- 加 `ID_W=4` 的 ID 信号，是因为**互连要同时服务 2 个主设备（桥、DMA）**，响应回来必须靠 ID 路由，否则多主会错乱——这正是"支持多主设备"的实现前提。

### 3.3 为什么 AXI 互连设"2 主 5 从"、而不是主从共享一条
- 主设备只有 2 个：**AHB2AXI 桥（CPU）** 和 **DMA 数据口**，对应 `s0_axi`、`s1_axi`；
- 从设备 5 个：FIR、DMA 配置口、SRAM、ROM、AXI2APB 桥，对应 `m0~m4_axi`；
- 分开成交叉开关（而不是一条共享总线）是**决赛加分项**，且从设备数量少、地址译码只看高位，逻辑简单。

### 3.4 为什么 DMA 要同时有 `s_axi`（配置）和 `m_axi`（数据）两个口
这是上一轮确认的**双角色**：CPU 经 `s_axi` 写源/目的/长度寄存器（从口、被动），DMA 经 `m_axi` 主动搬数据（主口、发起）。**两个口是两条独立 AXI 接口**，缺一个就违背赛题"每通道独立配置 + 支持 Burst 搬运"的要求。

### 3.5 为什么中断输出用"电平、高有效"、且 done 号 < error 号
- Cortex-M0 的 NVIC **只认电平敏感、高有效**中断，所以模块输出必须做成**电平**（置位后由 CPU 读 STATUS 寄存器清除，即 W1C），不能只给一个脉冲；
- done 在前、error 在后（IRQ0/1、IRQ2~7/IRQ8），直接落实《任务三》5.3 的优先级规则；
- DMA 的 6 个 done 用 `irq_done[5:0]` 一条 6 位总线，正好和 IRQ2~7 连续对位，软件里可按 `IRQ2+ch` 计算，省掉 6 根散线。

### 3.6 为什么 UART 的"物理口"和"寄存器口"要分开列
- `txd/rxd` 是**对外物理引脚**（异步串行线），是顶层集成信号的一部分，直接连板级；
- `PADDR/PWDATA/...` 是 **APB 寄存器口**，是 CPU 通过 AXI→APB 桥访问 `DATA/STATUS` 寄存器的路径；
- 两者性质完全不同（一个走内存映射，一个走芯片管脚），分开列才不会被误连。

### 3.7 为什么"存储接口"直接并入 AXI 从口、不单列
SRAM/ROM 对外**只有一条 AXI 从口**（内存映射），没有别的对外信号；例化 FPGA BRAM 原语时，其原生读写口属模块内部实现，不属于"对外接口"，所以本表不列，避免把实现细节泄漏到接口契约里。

### 3.8 为什么全片单一 `hclk` 时钟域
初赛目标主频 25MHz、目标 50MHz，且 M0、AXI、APB 天然同频同步。单时钟域意味着**没有跨时钟域(CDC)问题**，省掉一堆同步器，时序收敛也简单。UART 的波特率用片内分频器从 hclk 分出，`txd/rxd` 对外是异步串行线，但片内仍在 hclk 域采样。
