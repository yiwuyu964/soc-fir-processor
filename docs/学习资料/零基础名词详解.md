# 第 1 章 · 数字电路地基

### 0 和 1（比特 bit）
数字电路里只有两种状态：有电 / 没电，写成 1 和 0。一个 0/1 叫 1 个比特（bit）。
比喻：一个开关，开=1，关=0。

### 位宽（位宽 = 多少个 bit）
"16bit"就是 16 个并排的 0/1，能表示 2^16 = 65536 种组合。
比喻：16 个开关排成一排。
在项目：`fir_core.v` 里的 `DW=16`（数据 16 位）、`CW=16`（系数 16 位）。

### 逻辑门（Logic Gate）
对 0/1 做运算的小电路。最常见的三种：
- 与（AND）：两个都 1 才 1 → `&`
- 或（OR）：有一个 1 就 1 → `|`
- 非（NOT）：反过来 → `~`
比喻：与 = 串联开关（两个都开灯才亮）；或 = 并联开关（有一个开灯就亮）。

### 组合逻辑（Combinational Logic）
输出只由当前输入决定，没有记忆。比如"两个开关的与"。
在项目：`fir_core.v` 里的乘法 `p[g] = x[g] * h[g]`、加法 `sum = ...` 就是组合逻辑。

### 时序逻辑（Sequential Logic）
输出和"过去"有关，靠时钟和触发器来记忆。
比喻：组合逻辑像"即时反应"，时序逻辑像"记账本"——今天的结果取决于昨天记下的数。

### 时钟（Clock, clk）
一条周期性跳一下的电线（0→1→0→1……）。整个系统都踩着它的节拍。
比喻：乐队的节拍器，所有乐器按同一个拍子走。
在项目：每个模块都有 `input clk`。

### 时钟上升沿 / posedge
时钟从 0 跳到 1 的那一瞬间，叫上升沿。Verilog 里 `posedge clk` 就是"每当上升沿来"。
在项目：`fir_core.v` 的 `always @(posedge clk or negedge rst_n)`。

### 复位（Reset, rst_n）
按一下，让所有"记忆"清零，回到确定的起点。
`rst_n` 末尾的 `_n` 表示低电平有效（n = negative），意思是"0 表示在复位，1 表示正常工作"。
比喻：计算器的 C 键。
在项目：每个模块都有 `input rst_n`，里面 `if (!rst_n)` 就是"复位时清零"。

### 触发器 / 寄存器（Flip-Flop / Register）
能记住一个 0 或 1 的东西。每个上升沿，它把输入"抄"到输出，然后一直保持，直到下个上升沿。
这是数字电路里最重要的概念，没有之一。
比喻：一排带锁的抽屉，每个节拍把新值锁进去、旧的吐出来。
在项目：`fir_core.v` 里 `reg signed [DW-1:0] x [0:NTAP-1]` 就是 82 个 16 位的寄存器（延迟线）。

> 一句话区分：组合逻辑没有记忆，寄存器有记忆。所有"记住状态"的东西都是寄存器做的。

# 第 2 章 · Verilog 名词

### 模块（module）
Verilog 代码的基本单位，像一个"黑盒子"：有输入、有输出，里面是电路。
比喻：一个乐高积木块，有凸点（输入）和凹槽（输出）。
在项目：`module fir_core (...)` 就是定义了一个叫 fir_core 的模块。

### 端口（Port）
模块的输入输出接口——盒子外面露出来的"插头"。
- `input` = 输入（别人给它信号）
- `output` = 输出（它给别人信号）
比喻：电视机的电源口（输入）和 HDMI 口（输出）。
在项目：`fir_core.v` 里的 `input wire clk`、`output reg dout` 就是端口。

### wire（线）和 reg（寄存器类型）
- `wire`：一根连线，只能被 `assign` 驱动，不能存值（理解为"接出来的电线"）。
- `reg`：能保存值的变量，在 `always` 块里被赋值（理解为"抽屉里的值"）。
在项目：`fir_core.v` 里 `wire signed [DW+CW-1:0] p[...]`（乘积是线）、`reg signed [DW-1:0] x[...]`（延迟线是寄存器）。

### 模块实例化（Instantiation）
把一个模块"用起来"——在更大的模块里，把一个小模块当零件插进去。
比喻：图纸里写"这里放一个型号 XXX 的芯片"。
在项目：`soc_top.v` 里 `fir_axi #(...) u_fir (...)` 就是实例化了一个 FIR。

### assign（连续赋值）
给 `wire` 接线：右边一变，左边立刻跟着变（组合逻辑）。
在项目：`fir_core.v` 里 `assign p[g] = x[g] * h[g];`

### always 块
告诉电路"在某个条件发生时，执行里面的语句"。两种最常见：
- `always @(*)`：任何输入变了都重新算（组合逻辑）
- `always @(posedge clk)`：每个上升沿执行（时序逻辑，写寄存器）
在项目：`fir_core.v` 里加法树由 `generate` 生成的 `assign` 纯组合实现，延迟线移位用 `always @(posedge clk)`。

### 阻塞赋值 = 和非阻塞赋值 <=（Verilog 最容易搞混的地方）
- `=`（阻塞）：立刻生效，像"一句话说完再下一句"。
- `<=`（非阻塞）：等到这个上升沿结束时才统一生效，像"所有人同时把答案交上来"。
铁律：写时序逻辑（`always @(posedge clk)` 里）用 `<=`；写组合逻辑用 `=`。
在项目：`fir_core.v` 里 `x[0] <= din;` 用的是非阻塞。
我们真踩过的坑：测试台里撤 `valid` 信号如果用了 `=`，会抢在从设备采样前把信号清零，导致收不到——必须用 `<=`。

### 参数（parameter / localparam）
给模块留的"可调旋钮"，不用改代码就能换数值。
比喻：乐高说明书里"这个零件可以用 8 个齿的，也可以用 24 个齿的"。
在项目：`fir_core.v` 的 `parameter NTAP = 82`——改这个数字就能换阶数（81 阶 = 82 抽头）。

### 数组（Array）
一排同类型的变量，用下标访问。`x[3]` 就是第 4 个。
在项目：`reg [DW-1:0] x [0:NTAP-1]` 是 81 个寄存器的数组，就是 FIR 的延迟线。

### 有符号数（signed）
`wire signed` / `reg signed` 表示这个数是带正负号的（最高位是符号位）。
在项目：FIR 里数据和系数都是 `signed`，因为滤波样本有正有负。

### for / generate
批量写重复电路。`for` 在 `always` 里批量算；`generate...for` 在模块级批量"复制"硬件。
在项目：`fir_core.v` 里 `generate for (g=0; g<NTAP; ...)` 一次生成 82 个乘法器。

# 第 3 章 · 定点数与 FIR 名词

### 采样 / 样本（Sample）
把连续的信号（比如声音）每隔固定时间取一个数，取到的每个数叫一个样本。
比喻：拍视频其实就是每秒拍 30 张照片，每张照片就是一个"样本"。
在项目：`gen_fir_vectors.py` 生成的 `stim.hex` 里一行就是一个样本。

### 定点数 / Q1.15（Fixed-Point）
数字电路里没有小数，只有整数。但我们又要表示 -1 ~ +1 之间的小数，怎么办？
约定：真实值 = 整数 ÷ 32768（即 ÷ 2^15）。
所以 `32767` 表示 `1.0`，`16384` 表示 `0.5`，`-32768` 表示 `-1.0`。
这种"小数点位置固定"的表示法叫定点数，16 位、小数占 15 位的叫 Q1.15。
在项目：`fir_core.v` 注释里写着"x, h 都是 Q1.15：真实值 = 整数 / 2^15"。

### FIR 滤波器（Finite Impulse Response，有限冲激响应）
一种数字滤波器：把最近进来的 N 个样本，各自乘一个系数，再加起来，得到输出。
比喻：食堂打饭阿姨给你称重——最近几勺（样本）各自按份量（系数）算，再加总。
在项目：整个 `fir_core.v` 就是做这件事。

### 抽头 / 系数 / 阶数（Tap / Coefficient / Order）
- 抽头（tap）：延迟线上的一个"取数点"。
- 系数（coefficient）：每个抽头乘的那个数（决定滤波器特性：低通/高通等）。
- 阶数：N 个抽头对应 N−1 阶。赛题说的"81 阶"就是 82 个抽头，两者是同一件事，不是两种叫法。
在项目：`fir_core.v` 的 `NTAP=82`（82 个系数），`h[0..81]` 是系数寄存器。

### 延迟线 / 移位寄存器（Delay Line / Shift Register）
一串寄存器，每个节拍把数据往右推一格：新的进最左，旧的往右挤。
比喻：排队买票，每叫一个号，队伍整体前移一位。
在项目：`fir_core.v` 里 `for (i=NTAP-1; i>0; i--) x[i] <= x[i-1];` 就是移位。

### 卷积（Convolution）
FIR 的数学本质：输出 y[n] = Σ h[k]·x[n−k]，即"系数和过去样本错位相乘再求和"。
比喻：把滤波器系数当"模板"，在样本流上从头滑到尾，每滑一格算一次。
在项目：`gen_fir_vectors.py` 的 `golden_fir()` 函数就是按卷积公式算标准答案。

### 乘累加 MAC（Multiply-Accumulate）
"乘一个数 + 加到累加器"这个动作，是 FIR 的核心运算。
在项目：`03_mac/mac.v` 专门练这个。

### 累加器 / 位宽为什么是 40 位（Accumulator）
把 81 个乘积累加起来的"总账本"。最坏情况 81 × 32768 × 32768 ≈ 8.7×10^10，
32 位（最大 2.1×10^9）会溢出，所以要用 40 位（最大 1.1×10^12）。
在项目：`fir_core.v` 的 `AW=40`；详细推导见 `../任务5-FIR定点方案说明书.md`。

### 符号扩展（Sign Extension）
把 32 位的结果塞进 40 位的累加器时，负数要在前面补"1"、正数补"0"，否则负数会算错。
比喻：把 "-3" 从两位数扩成四位数要写成 "-003"，不能写成 "00-3"。
在项目：`fir_core.v` 里 `{{(AW-DW-CW){p[k][DW+CW-1]}}, p[k]}` 就是在复制符号位。

### 截位 / 右移 15 位（Truncation / Shift）
两个 Q1.15 相乘，结果是"除以 2^30"的量级；要回到 Q1.15，就要右移 15 位（相当于 ÷2^15）。
在项目：`fir_core.v` 的 `SHIFT = CW-1 = 15`，`sum[SHIFT+DW-1 : SHIFT]` 就是截取。

### 饱和（Saturation）
如果结果太大（溢出），不要"回绕"成反方向的尖峰，而是钳到最大/最小值。
比喻：音量条到顶了，就停在 100%，而不是爆音变 -100%。
在项目：`fir_core.v` 里的 `overflow` / `y_sat` 逻辑。

### 黄金模型 / 测试向量（Golden Model / Test Vector）
- 黄金模型：用 Python（软件）按同一公式算出"标准答案"。
- 测试向量：一组输入（激励）和对应期望输出（期望值），用来对照硬件对不对。
比喻：老师手里的标准答案和卷子。
在项目：`gen_fir_vectors.py` 生成 `stim.hex`（输入）、`exp.hex`（期望输出）。

### 逐位一致 / 误差 <0.1%
赛题要求"硬件结果和软件参考值误差 <0.1%"。我们做得更狠：要求每一位都完全一样（误差 = 0）。
在项目：测试台打印 `===== PASS: ... 与软件黄金模型逐位一致 =====`。

# 第 4 章 · SoC 名词

### CPU / 处理器（Processor）
"中央处理器"，能一条条执行指令的大脑。赛题指定用 Cortex-M0（ARM 的一款低功耗 32 位 CPU）。
在项目：仿真里没有真 CPU，用测试台里的"总线主设备模型（BFM）"扮演它；`sw/*.c` 是将来真 CPU 要跑的 C 程序。

### 外设（Peripheral）
CPU 之外的功能模块：FIR、UART、DMA、SRAM 都算外设。
比喻：CPU 是大脑，外设是手、嘴、眼睛。

### 总线（Bus）
让 CPU 和外设之间传数据的"公共马路"。赛题用 AXI（ARM 定义的一种高性能总线协议）。
比喻：一条所有人都能走的数据高速路。
在项目：`rtl/axi_lite_xbar.v`（互连）、`rtl/axi_lite_sram.v`（从设备）。

### 主设备 / 从设备（Master / Slave）
- 主设备：主动发起读写的一方（CPU、DMA）。
- 从设备：被动响应的一方（FIR、SRAM、UART）。
比喻：主设备是"点菜的人"，从设备是"上菜的人"。
在项目：测试台里的 BFM 是主；`fir.v`、`uart_apb.v`、`axi_sram.v` 是从。

### 握手 / valid-ready（Handshake）
传数据前双方"对拍"确认："我准备好了（valid）" / "我也准备好了（ready）"。
当 valid 和 ready 在同一个时钟上升沿同时为 1，这次传输完成。
比喻：交接接力棒——递的人举手（valid）、接的人伸手（ready），两手同时到位才算交接。
在项目：`rtl/axi_lite_sram.v` 的写/读通道；`06_axi_lite/tb_axi_sram.v` 里两个 task 是活的例子。

### AXI 的 5 个通道（Channel）
AXI 把一次读写拆成 5 条独立的"传送带"：
- 写地址 AW（我要写到哪个地址）
- 写数据 W（写什么数据）
- 写响应 B（写完了，回个"收到"）
- 读地址 AR（我要读哪个地址）
- 读数据 R（这是你要的数据）
在项目：`axi_lite_sram.v` 端口注释里每一条都标了 AW/W/B/AR/R。

### 地址（Address）
CPU 眼里，所有东西（内存、外设）都在一条长长的"门牌号"上。每个字节一个编号。
比喻：城市里每户一个门牌号。
在项目：`axi_lite_xbar.v` 里 `0x0000_0000` 这种就是地址。

### 地址映射表 / 内存地图（Address Map / Memory Map）
一张"哪段地址归哪个外设"的表。CPU 想知道某个外设在哪，就查这张表。
在项目：`rtl/axi_lite_xbar.v` 顶部注释，和 `sw/fir_regs.h` 里对应：

| 地址段 | 外设 |
|---|---|
| 0x0000_0000 | FIR 滤波器 |
| 0x0000_1000 | UART |
| 0x0000_2000 | SRAM |

### 基地址 / 偏移（Base Address / Offset）
- 基地址：一个外设从哪个地址开始（比如 UART 从 0x1000 开始）。
- 偏移：外设内部某个寄存器离基地址多远（比如 UART 的状态寄存器在 +0x004）。
比喻：基地址是"小区门牌"，偏移是"几单元几号"。
在项目：`sw/fir_regs.h` 里 `#define UART_BASE 0x00001000`（基地址）、`UART_STATUS (UART_BASE+0x004)`（偏移）。

### 寄存器 / 外设寄存器（Register / Peripheral Register）
CPU 控制外设的开关：往某个地址写一个数，就是拨动外设的一个"开关"。
这是"软硬件协同"的核心概念——CPU 不认识外设内部，它只会读写地址。
比喻：开车不需要懂发动机，只需要踩油门（写寄存器）、看仪表盘（读寄存器）。
在项目：`sw/fir_driver.c` 里 `REG32(FIR_DIN) = sample;` 就是"把样本写进 FIR 的 DIN 寄存器"。

### 内存映射 IO（Memory-Mapped I/O）
"把外设当成内存一样读写"的做法。CPU 访问外设 = 读写特定地址。
在项目：整个 `sw/` 就是靠这个机制控制 FIR 和 UART。

### 桥（Bridge）
两种不同协议之间的"翻译官"：赛题要 AHB→AXI 桥（Cortex-M0 用 AHB，外面是 AXI）和 AXI→APB 桥（UART 这种慢外设挂 APB）。
比喻：不同国家的人对话，中间站个翻译。
在项目：AHB→AXI 桥已经内置在 Cortex-M0 核里（实验 09，核对外直接是 AXI 口）；UART 直接做成 AXI 从设备（简化了，AXI→APB 桥是进阶）。

### DMA（Direct Memory Access，直接存储器访问）
一个能干搬运活的主设备：CPU 告诉它"从 A 搬到 B、搬多少"，它自己搬，搬完报告，CPU 不用一个个搬。
比喻：CPU 是老板，DMA 是搬运工——老板交代一句，搬运工自己搬完。
在项目：`rtl/dma.v`（实验 10，6 通道，已独立验证 PASS）；接入 SoC 的"双主仲裁"是进阶。

### 中断（Interrupt）
外设"叫醒"CPU 的一种机制：干完活了拉一下"门铃"，CPU 暂停手头的事来处理。
比喻：办公室门铃。
在项目：`rtl/dma.v` 里"传输完成拉 irq"已经做了；把 irq 接到 CPU 的 NVIC 是进阶。

### SRAM（Static Random-Access Memory）
可读写的存储器，掉电丢数据，但快。SoC 里放程序和数据。
在项目：`rtl/axi_lite_sram.v` 就是一块小 SRAM。

### FIFO（First-In First-Out，先进先出队列）
一个"排队缓冲"：先写进去的先读出来。用来匹配快慢不一的双方。
比喻：收银台排队——先来的先结账。
在项目：`rtl/sync_fifo.v`，FIR 拼命吐结果、CPU 慢慢读，中间就靠它缓冲。

### 仲裁（Arbitration）
多个主设备同时想用总线时，决定"让谁先走"。
比喻：十字路口红绿灯。
在项目：`axi_lite_xbar.v` 目前只有 1 个主（不需要仲裁），多主仲裁是"下一步"。

### 时钟频率 / 主频（Clock Frequency）
时钟每秒跳多少次，单位 MHz（兆赫兹）。赛题要求 ≥25MHz，目标 50MHz。
比喻：节拍器一分钟打多少拍。
在项目：测试台 `always #5 clk = ~clk;` 就是 100MHz（周期 10ns）。

### 吞吐量（Throughput）
每拍能处理几个样本。赛题要求 FIR ≥1 sample/cycle（每时钟至少 1 个样本）。
在项目：`fir_core.v` 是全并行，正好 1 sample/cycle。

### 时序收敛（Timing Closure）
信号从一处传到另一处需要时间；时钟太快、路太长，信号就"赶不上"，叫时序不收敛。
比喻：接力跑，路太长、发令太快，下一棒还没就位。
在项目：81 项串行加法组合路径太长，50MHz 大概率不收敛，要改流水线加法树（决赛/上板的事）。

# 第 5 章 · 验证与工具名词

### Testbench（测试台）
一段不用上板、只在电脑里仿真的代码，用来"假装外部世界"，给模块喂信号、看输出对不对。
比喻：给机器做台架测试，而不是直接上路。
在项目：每个 `tb_*.v` 都是 testbench。

### 仿真（Simulation）
在电脑上用软件"跑"你的电路，看信号怎么变。
在项目：跑 `sim\sim.cmd 08_soc` 就是仿真。

### BFM（Bus Functional Model，总线功能模型）
testbench 里扮演"CPU"的一段代码，专门按总线协议发读写。
在项目：`08_soc/tb_soc.v` 里的 `axi_write` / `axi_read` 两个 task。

### 波形 / VCD / GTKWave
仿真时把所有信号随时间的变化录下来（VCD 文件），用 GTKWave 打开，像看心电图一样看电路。
在项目：`sim.cmd` 会自动打开 GTKWave；`GTKWave入门.md` 教怎么看。

### 自校验（Self-Checking）
testbench 自己比对结果、自己打印 PASS/FAIL，不用人肉盯波形。
在项目：每个 `tb_*.v` 最后都打印 `===== PASS ... =====` 或 FAIL。

### 综合（Synthesis）
把 Verilog 代码翻译成 FPGA 芯片上真实的电路（逻辑门、触发器）。
比喻：把图纸变成真房子。
在项目：这是上板前的一步，`rtl/` 里的代码都要保证"可综合"（不能有 `$display` 这类仿真专用语句）。

### 布局布线 / 上板（Place & Route / Implement）
综合之后，把电路"摆到芯片上、连好线"，下载到 FPGA 开发板跑。
在项目：赛题要求用紫光同创 Logos-2 开发板 + 厂商 EDA 工具。

### LUT / FF / BRAM / DSP
FPGA 芯片里的四种"基本资源"：
- LUT：万能小逻辑表（实现组合逻辑）
- FF：触发器（实现寄存器）
- BRAM：内置存储块
- DSP：硬核乘法器（81 个并行乘法就吃 81 个 DSP）
决赛看"占用率"：同等功能下资源用得越少分越高（所以要做对称优化把乘法器减半）。
在项目：`fir_core.v` 全并行 = 82 个 DSP；对称优化后 = 41 个。

### iverilog / vvp / GTKWave / VSCode / git
- iverilog：把 Verilog 编译成仿真程序（开源编译器）。
- vvp：运行编译出来的仿真。
- GTKWave：看波形。
- VSCode：写代码的编辑器。
- git：版本管理（改动留痕，方便回溯）。
在项目：`sim.ps1` 自动调 iverilog+vvp+GTKWave；赛题推荐这套开源工具链。

## 最后：怎么用这份文档配合项目学习

1. 第 1 天：只读第 1、2 章，然后跑 `sim\sim.cmd -Only axi_sram`，对着 `RTL/axi_sram.v` 找"时钟、复位、寄存器、端口、非阻塞赋值"。
2. 第 2~3 天：读第 3 章，跑 `sim\sim.cmd -Only fir`，对着 `RTL/fir_core.v` 找"延迟线、系数、卷积、右移 15 位、40 位累加器"。
3. 第 4~5 天：读第 4 章上半（总线/主从/握手/地址），跑 `sim\sim.cmd -Only phase5`，死磕 `TB/axi_sram.v` 里的两个 task。
4. 第 6~7 天：读第 4 章下半（寄存器/DMA/FIFO），跑 `sim\sim.cmd -Only dma`，对着 `RTL/fir.v`、`sw/main.c` 找"寄存器、地址映射、软硬协同"。
5. 第 8 天起：再看[学习指南.md](学习指南.md)串起整体思路；有余力看[Cortex-M0集成说明.md](Cortex-M0集成说明.md)和跑 `sim\sim.cmd -Only phase6`（FIR×DMA 端到端）。
